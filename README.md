# dirglob

A Ruby Dir.glob/File.fnmatch compatible C99 library with clean-room implementation.

## Features

- Ruby 4.0 Dir.glob/File.fnmatch specification compliant
- Cross-platform (Linux, macOS, Windows)
- Single-header library
- No external dependencies (libc only)
- MIT License

## Legal Notice

This library is a **clean-room implementation** based solely on:
- Ruby official documentation (https://docs.ruby-lang.org/)
- Public specification and test cases
- Independent algorithm design

**We do NOT reference Ruby (MRI) source code** to avoid any licensing conflicts.
