# glob互換性テスト失敗分析レポート

実行日: 2026-01-22

## 現状

連続スラッシュの保持機能を実装中。trailing_slashesの追加により新たな問題が発生。

## 調査結果: 連続スラッシュについて

**重要な発見**: Rubyは結果に連続スラッシュを**保持**します。

### パターン例: `*/*//*///*`

このパターンは以下のように解釈されます:
- セグメント1: `*` (trailing slash: 1)
- セグメント2: `*` (trailing slash: 2)
- セグメント3: `*` (trailing slash: 3)
- セグメント4: `*` (trailing slash: 0)

### Ruby期待値の例:

```
./.hidden//.subhidden0///.hiddenfile0
07_recursive/dir2//dir2///file2.txt
```

連続スラッシュがパス内に保持されています。

### 実装の課題

1. `rbc_build_path_with_slashes`関数を追加してtrailing_slashesを保持
2. しかし、既存のテストで新たな失敗が発生 (824件→3666件)
3. パス組み立てロジックの見直しが必要

## 次のステップ

連続スラッシュ実装を一旦ロールバックし、より慎重にアプローチする必要がある。

### 2. ドットファイル + 再帰パターン

**パターン**: `**/.*`

**問題**:
- 期待値: 41件
- 実際: 105件
- 差分: +64件

**原因**:
- `.`や`..`を含めて返している可能性
- 中間ディレクトリ自体も含めている可能性
- `DOTMATCH`フラグがない場合でもドットファイルを返している

**影響**: 57件のテスト失敗

**関連パターン**:
- `.**/*/` - 期待18, 実際30 (+12)
- `.hidden/.**/.*` - 複数のドット処理
- `.*/.*` - ドットファイルのネスト

**修正方針**:
- ドットファイルのフィルタリングロジックを見直す
- `.`と`..`を明示的に除外
- 再帰時のドットファイル処理を確認

### 3. ソート順の不一致

**パターン**: `09_combined/*/*.{c,h}`

**問題**:
- 期待: `09_combined/dir0/filb.c`
- 実際: `09_combined/dir0/fila.h`
- インデックス1の位置で不一致

**原因**:
- ブレース展開後のソート順が異なる
- Rubyは拡張子ごとにグループ化してソート（.c, .h の順）
- 現在の実装は単純なアルファベット順

**影響**: 299件のテスト失敗

**Rubyの期待値の順序**:
```
fila.c
filb.c
filc.c
fila.h
filb.h
filc.h
```

**現在の実装の順序**:
```
fila.c
fila.h
filb.c
filb.h
filc.c
filc.h
```

**修正方針**:
- ブレース展開の実装を確認
- パターンごとに結果を取得してマージする順序を見直す

### 4. ブレース展開の不完全性

**パターン**: `05_braceexpansion/{{a`

**問題**:
- 期待値: 3件
- 実際: 1件
- 差分: -2件

**原因**:
- `{{`をエスケープシーケンスとして扱えていない
- `{{a`は`{a`, `{a`, `a`の3パターンに展開されるべき
- 現在は`{a`のみに展開されている

**影響**: 44件のテスト失敗

**関連パターン**:
- `{dir1...}` - 不完全な展開
- `{file[0-9].txt}` - ブレース内のパターン

**修正方針**:
- ブレース展開のパーサーを修正
- エスケープルール（`{{` -> `{`）を実装
- ネストしたブレースの処理

### 5. その他の再帰パターン問題

**パターン**: `**/**`, `.hidden/.**/*`など

**問題**:
- 二重再帰パターンの処理
- ドットディレクトリ内の再帰検索

**影響**: 66件のテスト失敗

### 6. 特殊パターン

**パターン**: `..` (親ディレクトリ参照)

**問題**:
- 期待値: 0件
- 実際: 1件
- `..`を文字列パターンとして扱うか、ディレクトリとして扱うかの判断

**影響**: 33件のテスト失敗

**空パターン**:
- 期待値: 0-1件
- 問題なし（正常に処理されている）
